Purpose:

The Partner Room is a controlled private briefing space for hotel operators, integration partners, commercial partners and platform collaborators.

The current WELBX platform has a lot of depth. The Partner Room must simplify the experience into a curated partner journey. It should feel like a premium enterprise deal room, not a dashboard and not a public marketing site.

Use the current dark, premium WELBX style:

* navy / black background
* white typography
* gold highlight
* signal blue where appropriate
* no emojis
* no generic SaaS graphics
* zero clutter
* executive-grade spacing
* sharp rectangular cards
* strong hierarchy

App implementation requirements:

1. Add PartnerRoom pages inside src/pages.
2. Add routes to App.tsx.
3. Suppress the standard Sidebar and GlobalSearch for /partner-room routes, the same way /story and /presentation-mode are treated.
4. Create a simple top navigation inside Partner Room:

   * Overview
   * Operator Brief
   * Integration
   * Moments Economy
   * Signals Engine
   * Pilot Model
   * Commercial Model
   * Demo Paths
5. Reuse existing data from:

   * src/data/moments.ts
   * src/data/signals.ts
   * src/data/scenarios.ts
   * existing story/presentation pages where helpful
6. Do not add new packages.
